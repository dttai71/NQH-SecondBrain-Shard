# Context — Để AI hiểu bạn (Hermes)

> Nơi mô tả **bạn** cho AI agent: vai trò, phòng ban, công cụ bạn dùng, cách bạn muốn làm việc. AI đọc đầu mỗi phiên để cá nhân hóa.

## Có gì ở đây

- [[My-Role]] — **quan trọng nhất** — vai trò, phòng ban, PC/BU, trách nhiệm. Điền ngay khi bắt đầu.
- [[Working-Preferences]] — cách bạn muốn AI hỗ trợ (ngôn ngữ, phong cách, quy tắc riêng).
- [[My-Tech-Stack]] — công cụ/ngôn ngữ/quy ước bạn dùng (chỉ cần nếu làm kỹ thuật).

## Cách dùng

- Khi đổi vai trò/phòng ban/công cụ/cách làm → **sửa file ở đây**. Phiên sau AI tự dùng.
- Giữ ngắn gọn, cập nhật dần.
